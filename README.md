This is a transformer that lifts (timbre-neutral) pitch data to higher-dimensional orchestral timbre space, using a MIDI corpus assembled by IRCAM for their Live Orchestral Piano project for training. Input and output as MusicXML files with high bandwidth for notational complexity (e.g., nested tuplets).

Forthcoming updates include a more diverse training corpus, a navigable latent space, and a front-end in Manuscript (e.g.) for use as a plug-in in traditional notation programs.
