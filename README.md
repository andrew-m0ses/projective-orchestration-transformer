This is a transformer that lifts timbre/instrument-neutral pitch data in the form of MusicXML files to higher-dimensional orchestral timbre-space, using a MIDI corpus assembled by IRCAM for their Live Orchestral Piano project for training.

Forthcoming updates include a more diverse training corpus, a navigable latent space, and a front-end in Manuscript (e.g.) for use as a plug-in in traditional notation programs.
